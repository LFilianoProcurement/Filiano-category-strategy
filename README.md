# 🎯 Category Strategy Generator

AI-powered procurement category strategy builder. Part of the Filiano Procurement AI Portfolio (Project 7).

## Features

- **Porter's Five Forces** – automated market structure analysis
- **Kraljic Matrix** positioning with rationale
- **SWOT Analysis** tailored to the category and context
- **Sourcing Strategy Recommendation** with negotiation levers
- **5 Key Initiatives** sorted by timeline and priority
- **Risk Register** with likelihood/impact scoring and mitigations
- **KPIs & Metrics** with targets and review frequency
- **Savings Opportunity** estimate

## Setup

1. Clone or upload to your Streamlit Cloud workspace
2. Add your `ANTHROPIC_API_KEY` to Streamlit Secrets:
   ```
   ANTHROPIC_API_KEY = "sk-ant-..."
   ```
3. Deploy — no other configuration needed

## Usage

1. Enter category details in the left sidebar
2. Click **Generate Strategy**
3. Navigate the tabbed output
4. Download the full strategy as JSON
